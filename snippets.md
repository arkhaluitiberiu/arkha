## FLOW

- `arkhapitol` → Structură HTML pentru o pagină de capitol din Arkha lui Tiberiu





- `cuprinscap` → Element de listă pentru un capitol nou în cuprins

## ELEMENTE EXTRA
- `figcap` → imagine + caption

- `subsol` → Inserare notă de subsol

- `sitemap` → Bloc URL pentru sitemap.xml cu data curentă automat
- `sitemap-img` → capitol nou în sitemap cu imagine
