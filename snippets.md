## FLOW

- `arkhapitol` → Structură HTML pentru o pagină de capitol din Arkha lui Tiberiu

- `sitemap` → Bloc URL pentru sitemap.xml cu data curentă automat

- `cuprinscap` → Element de listă pentru un capitol nou în cuprins


# FLOWCHART
1. creaza .html nou
2. Adauga structura html folosind comanda **arkhapitol**
3. Adauga link-urile in *navigatie* la capitolul precedent
4. Adauga link-ul in cuprins
5. Adauga link-ul in sitemap    *sitemap-img* daca articolul are imagini relevante.
6. push



## ELEMENTE EXTRA
- `figcap` → imagine + caption
- `nota` → Referință superscript in paragraf către o notă de subsol
- `subsol` → Inserare notă de subsol
- `sitemap-img` → capitol nou în sitemap cu imagine
